# Third-party notices

## Runtime dependency

- **NumPy** — BSD-3-Clause. Install via `requirements.txt`. Not redistributed in this archive.

## Evaluation data provenance (boxes / times only)

This package redistributes **prediction and GT boxes, temporal intervals, and
identifiers** needed to recompute frozen protocol scores for:

- Datasets: VidSTG, HC-STVG (upstream dataset licenses apply to raw videos; videos are **not** included)
- Detectors / STVG models: TubeDETR, DeViL (model code and weights are **not** included)

No third-party model repositories, checkpoints, or raw video files are shipped here.
